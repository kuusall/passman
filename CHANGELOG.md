# Changelog

## 1.0.0 - 2026-09-10

- Completed the local encrypted-vault password manager milestone.
- Added versioned vault storage, authenticated encryption, Argon2id key
  derivation, password rotation, CRUD, search, import/export, generation, and
  clipboard timeout behavior.
- Added malformed-input hardening and sensitive-buffer cleanup on vault-open
  failure paths.
- Added CMake installation support, release documentation, sanitizer CI, and
  macOS arm64 packaging metadata.

## Unreleased

No planned feature work. Bug fixes and security fixes may be released as
patch versions.
